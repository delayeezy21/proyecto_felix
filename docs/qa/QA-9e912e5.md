## Calidad de los adaptadores (revisión de código + tests)
- Sin claves en el código: `git grep` de `AIza`/`key=` solo encuentra el paso de `Env.mapsApiKey` (dart-define). En Android la clave llega al manifiesto por `manifestPlaceholders` desde `dart-defines`.
- User-Agent de Nominatim genérico (`ProyectoFelix/0.1 (cl.proyectofelix.proyecto_felix)`), sin correo ni datos del usuario; en Web no se fija (test). Las URLs solo llevan la consulta, `countrycodes=cl`, idioma y, en reverse, lat/lng con 6 decimales. Google añade `key` (obligatorio en la API REST).
- Sin red en tests: geocoding con `MockClient`; tiles OSM con un `TileProvider` falso; el SDK de Google con un loader/plataforma falsos.
- Windows (y iOS, `other`) → OSM tanto para mapa como para geocoding (`env_test`: "Windows siempre usa OSM"); Web usa Nominatim para geocoding.
- Cola serial de 1,1 s, caché LRU de 100 entradas, deduplicación en vuelo y no se cachean errores: cubiertos por tests de contrato.

## Riesgos y lo que NO se probó (y por qué)
- **UI web real en Chrome**: la extensión Claude in Chrome no estaba conectada. La UI quedó cubierta solo por widget tests con adaptadores falsos.
- **Android/iPhone/Windows reales**: sin dispositivo ni build nativo en esta iteración.
- **Proveedores reales** (Google Maps/Geocoding, Nominatim, tiles OSM): no se llamaron, a propósito. Riesgo: la API REST de Geocoding de Google no acepta claves restringidas por app Android sin cabeceras `X-Android-Package`/`X-Android-Cert`; con la restricción que sugiere `env.example` podría responder `REQUEST_DENIED` en Android (la app muestra "marca el punto en el mapa"). Verificar con una clave real antes de producción.
- Tiles y Nominatim públicos de la OSMF por defecto: válidos solo para desarrollo (documentado en `Env`); en producción hay que configurar `OSM_TILE_URL`/`NOMINATIM_URL`.
- Microchip no es único entre dueños (dos dueños pueden registrar el mismo número). No lo exige el SPEC; queda como decisión pendiente para la fase 7.
- `EXPLAIN` con datos sintéticos (5.000 dueños, 4 mascotas y 2 direcciones cada uno); no se midió con distribución real.
