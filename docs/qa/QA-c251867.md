## Riesgos y lo que NO se probó (y por qué)
- Login con Google: sin proveedor OAuth configurado en local.
- UI real en Android, Windows, Web e iPhone: no hubo automatización de dispositivo. Solo widget tests y la API.
- La purga invocada por pg_cron con secretos de Vault: no hay secretos en local. Se probó la Edge Function directo (vet_e2e).
- El aviso al vet tras la revisión (HU1.4) y "en línea" (HU1.5) aún no están implementados.
- `auth_e2e`, `vet_e2e` y el smoke dejan usuarios `*@test.local` en la base compartida (63 al momento del QA). No se borraron porque no los creó este QA.
